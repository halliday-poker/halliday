# Scoring and rounds

How chips become game points, game points become placement points, and tables regroup.

1.  Teams are grouped into tables of about 5, randomly in round one.
2.  Each round, every table plays one game per seat (5 games at a 5-bot table). Final chips rank each game and convert to points: 1st gets 5, 2nd gets 4, down to 1.
3.  A table’s game points total converts to **round placement points** the same way: best in your group gets 5, and so on. Ties share the average of the places they cover (two bots tied for 2nd each get 3.5). The scale follows the table size.
4.  Groups reshuffle by cumulative placement points each round (ties broken by total game points), so you increasingly face bots at your level.
5.  After 4 rounds, the sum of round placement points decides the final standings, and the top 3 win prizes. Ties for a prize are settled with a head-to-head set between the tied bots, one game per seat.

One round at a 5-bot table

Chips rank each game, game points rank the round.

Judging runs automatically before the closing ceremony. The ceremony replays the games on the big screens, every hole card face up, and the standings are revealed round by round.
